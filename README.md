# GreenTrack – Smart Waste Management and Sustainability Platform

This project delivers a Salesforce-based waste management and sustainability platform for residents, field teams, and municipal administrators. It includes custom objects for residents, complaints, collection records, recycling requests, service teams, Apex automation, flows, reports, and a Lightning application.

## Project structure

- `force-app/main/default` – Salesforce metadata
- `manifest/package.xml` – package manifest for deployment and retrieval
- `docs/` – project documentation
- `scripts/` – sample data and Apex scripts

## Key objects

- `Resident__c`
- `Waste_Complaint__c`
- `Service_Team__c`
- `Recycling_Request__c`
- `Waste_Collection__c`

## Notes

This project is designed for deployment to a Salesforce Developer Edition or Trailhead Playground connected via Salesforce CLI.
